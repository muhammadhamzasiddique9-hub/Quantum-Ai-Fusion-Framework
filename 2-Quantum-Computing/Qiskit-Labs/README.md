# My First Quantum Circuit ⚛️

This repository contains my very first quantum computing circuit built using **Qiskit** and **IBM Quantum** concepts.

## 📌 Overview
In this notebook, I explored the fundamental concepts of Quantum Computing, including:
- **Qubits** (Quantum Bits)
- **Superposition** using the Hadamard ($H$) Gate
- **Bit Flips** using the Pauli-X ($X$) Gate
- **Quantum Entanglement** & Multi-qubit interactions
- **Measurement** of quantum states into classical registers

## 🛠️ Circuit Architecture
The quantum circuit consists of:
- **2 Qubits** (`q_0`, `q_1`)
- **2 Classical Bits** (`c`)
- **Hadamard Gate ($H$)** applied to `q_0` to create superposition.
- **Pauli-X Gate ($X$)** applied to `q_1`.
- **Measurement Gates ($M$)** mapping quantum outputs to classical bits.
